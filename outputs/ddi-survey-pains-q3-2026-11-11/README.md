# Боли команд B2C — опрос DDI, III квартал 2026

Актуальный результат — [тематический HTML-отчёт](Боли_B2C_по_проблематике_III_квартал_2026.html): шесть тем, восемь закрытых категорий, пересечения жалоб, наблюдения и цитаты команд. [Предыдущий отчёт с декомпозицией по юнитам](Боли_команд_B2C_III_квартал_2026.html) сохранён без изменений. Исходники текущей тематической версии находятся в `report-app/src/content/report/`, проверенный набор данных — в `report-app/src/data.json`.

Требование пользователя к тексту: простой русский язык, только факты, инсайты и наблюдения. Без авторских рекомендаций и советов внутри выводов. В пользовательских подписях не используются «флаги» и служебные объяснения устройства анкеты. Подпись первой группы сравнения: «Жалуются только на T2M витрин». Сравнение относится к двум выбранным проблемам; у команд могут быть другие жалобы. Дословные цитаты сохраняются.

Внутри каждой из шести тем добавлен хитмап по восьми юнитам. Всего показаны 64 ячейки: восемь отдельных проблем × восемь юнитов. В каждой ячейке доля и число команд юнита; для всех карт используется одна шкала 0–100%. BI и Self-Service, алерты и автоматизация отчётности показаны отдельными строками. Источник — проверенный набор `unit_pains`. Выбор ячейки открывает реестр соответствующих команд.

## Данные и воспроизведение

`node outputs/ddi-survey-pains-q3-2026-11-11/analyze.mjs` из корня репозитория повторно проверяет SHA256 исходных CSV, объединяет повторные выгрузки, исключает две ранее согласованные тестовые анкеты и сохраняет `reviewed.json` и `validation.json`.

Исходная нормализация: `../ddi-q3-survey-export-2026-11-11/responses.json`. Текущий реестр команд: `../ddi-q3-survey-export-2026-11-11/data.json`. Анализ использует 79 анкет за III квартал 2026, полученных 15–28 октября, от 76 канонических команд восьми юнитов. Для трёх команд с двумя анкетами закрытые варианты объединены; каждая команда учитывается в одной боли максимум один раз.

Знаменатель общих долей — 76 команд; в разрезе юнитов — число команд соответствующего юнита. Множественный выбор: сумма долей может превышать 100%. Свободные комментарии не добавляются к частотам закрытых вариантов. Ручная классификация десяти комментариев сохранена в `analyze.mjs`.

74 команды отметили ограничение или потребность в поддержке; одна прямо сообщила об отсутствии действующих критичных проблем; одна оставила только «-» в «Другое». Вопрос был обязательным и не содержал отдельного варианта «всё устраивает»: эти числа описывают ответы и не измеряют удовлетворённость всех команд. Частота упоминания не измеряет тяжесть проблемы.

Срез источников — 28 октября 2026. Дата сборки анализа — 11 ноября 2026.

Сборка использует установленный Data App runtime, без изменения его защищённых файлов. Самодостаточный HTML формируется штатным `export-offline`; split-файл `report-app/dist/index.html` требует соседний JSON-файл данных и служит для локального HTTP-предпросмотра.

## Проверки

`node outputs/ddi-survey-pains-q3-2026-11-11/validate-report.mjs` проверяет данные, знаменатели, цитаты, хеши сборки и идентичность данных переносимого HTML. Результат: `tester-validation.json`.

Для тематической версии: `node outputs/ddi-survey-pains-q3-2026-11-11/validate-topics-report.mjs`. Результат: `tester-topics-validation.json`. Пересечения считаются по уникальным командам: витрины/ресурсы — 24/22/19 (объединение 65); BI/Self-Service — 26/5/6 (37); алерты/автоматизация отчётности — 13/11/11 (35). В каждой тройке второй показатель означает обе опции, остальные — выбранную опцию без второго флага. Команды могут иметь другие боли; объединения трёх тематических пар пересекаются и не суммируются.

В браузере проверены диаграммы, матрица юнитов, таблицы, цитаты, фильтр юнита и соответствие строк в просмотре источника, экран 390 px и обычная ширина. Ошибок в консоли и горизонтального переполнения страницы не обнаружено. Постоянный preview-service не запустился; текущий HTTP-предпросмотр работает на временном сервере. Переносимый HTML самодостаточен.
