# Сценарий восстановления знания продуктов-спутников

Это отдельный расчёт. Канонические оценки и приложение не изменены. Базой служит текущий runtime III квартала 2026: 76 команд, загруженный backlog, последние 34 подтверждённые пары сегментов и каналов, включая 100% Навигатора у «Детей».

Восстанавливается только `general.znanie_produktov_sputnikov` по 54 явным оценкам `all-satellites-knowledge-q3-2026.json` от 30 октября 2026. Значение существующей применимой метрики доводится до её текущего максимума. Навигатор и другие зависимые показатели не пересчитываются. Состав команд, применимость, веса и все остальные оценки остаются текущими.

Запуск из корня:

```sh
node outputs/ddi-satellites-restore-2026-11-11/scenario.mjs
```

Команда записывает только соседний `scenario.json`. Экспорт `runScenario()` возвращает `{result,current,scenario}` для независимой проверки без записи. Встроенные assertions проверяют сохранность источников, Q2, всех остальных метрик с provenance и 426 отслеживаемых production-файлов по SHA256.

Из 54 сопоставленных применимых фактов уже полные 44; ниже максимума 10: два нуля и восемь оценок 50%. Пропусков нет; все 76 команд имеют рассчитываемый DDI до и после. У всех десяти текущий источник — `keyMetricsPreviousQuarterFallback`: финальное правило от 2 ноября заменяет раннюю оценку переносом Q2 для отсутствующей пары workbook. Это подтверждается кодом финального resolver и сохранённым provenance каждой пары. Исключений и несопоставленных исторических команд нет.

Ранги в таблице соревновательные: 1 плюс число команд со строго более высоким **округлённым** DDI. Равные DDI имеют одинаковое место. Поэтому КАСКО может опуститься в ранге при небольшом росте сырого DDI: его округлённый балл остаётся 71, а другая команда его обгоняет. JSON дополнительно содержит порядковую позицию при сортировке по округлённому DDI и каноническому имени, с тем же `Intl.Collator('en', {sensitivity:'base', numeric:true})`, что в приложении. Отображаемые названия берутся из существующего `displayProductName`; канонические имена и идентификаторы сохранены.

Общий DDI: среднее округлённых командных баллов 63,842105 → 63,934211 (+0,092105 п.п.); карточка **64 → 64**. Дополнительное среднее сырых DDI: 63,879770 → 63,944859. Среди 60 продуктов среднее округлённых баллов 62,316667 → 62,433333 (+0,116667 п.п.), карточка **62 → 62**. Все знаменатели и состав оцениваемых команд сохраняются.

Единственный переход уровня — **ОСАГО: 80 → 81, «Зрелые» → «Лидеры Data Driven»**. Уровень определяется действующим `maturityLevelName` по округлённому баллу. Распределение всех 76 команд: лидеры 7 → 8, зрелые 43 → 42, развивающиеся 23 → 23, требуют внимания 3 → 3. Среди 60 продуктов: лидеры 4 → 5, зрелые 33 → 32, развивающиеся 20 → 20, требуют внимания 3 → 3.

В общем рейтинге меняется соревновательный ранг 13 команд: семь из десяти с изменением спутников и шесть без изменения этой метрики. Порядковая позиция меняется у 14 команд: шести с изменением спутников и восьми без. Если объединить оба определения и оба рейтинга, движения есть у 17 команд; у десяти из них метрика спутников не менялась. Все движения полностью перечислены в `summary.rankingMovements` и `unchangedMetricRankMovements`. `unchangedScoreRankMovements` — отдельный список команд без изменения округлённого DDI; он включает КАСКО с небольшим ростом сырого балла.

Файл `scenario.json` содержит исходные 54 пары с историческим и текущим provenance, результаты всех 76 команд, оба определения ранга в двух составах, сырые и округлённые DDI, уровни, coverage, контрольные суммы входов и production-файлов. Исторические экспорты и данные опросников не менялись.
