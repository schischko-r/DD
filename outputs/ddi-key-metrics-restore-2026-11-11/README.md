# Отдельный сценарий восстановления оценок на 30 октября 2026

Канонические данные и приложение не изменяются. В расчёте используются текущие эффективные оценки III квартала, включая подтверждение MAU ЕЛК от 11 ноября. Поверх результата полного runtime-конвейера восстанавливаются только 28 зафиксированных на 30 октября значений блока `general` у сегментов и каналов. Это точечный сценарий, а не полный откат приложения на историческую дату.

Запуск из корня репозитория:

```sh
node outputs/ddi-key-metrics-restore-2026-11-11/scenario.mjs
```

Скрипт читает список актуальных overlays из `App.jsx`, запускает `buildDdiPeriodProducts` с загруженным `backlog-data.json` и создаёт только соседний `scenario.json`. Дополнительные зависимости не устанавливаются. Экспорт `runScenario()` возвращает оба массива эффективных продуктов для независимой проверки без записи результата.

Источники исторических значений:

| Файл в gravity-app/src/data | Фактов | Характер |
| --- | ---: | --- |
| segment-user-assessments-q3-2026.json | 21 | Прямые оценки сегментов |
| pb-nonfinancial-knowledge-q3-2026.json | 1 | PB, 2+ нефинансовых сервисов = 50% |
| pb-navigator-knowledge-q3-2026.json | 1 | PB, Навигатор = 100% |
| working-age-fot-knowledge-q3-2026.json | 1 | Рабочий возраст, доля рынка ФОТ = 100% |
| knowledge-user-assessments-q3-2026.json | 1 | Чат, Навигатор = 100% |
| navigator-market-knowledge-q3-2026.json | 1 | ЕЛК, материализованное пользовательское правило |
| navigator-mau-knowledge-q3-2026.json | 2 | СБОЛ и Уведомления, материализованное пользовательское правило |

Три последних канальных значения ЕЛК/СБОЛ/Уведомления получены из подтверждённых пользователем правил, а не из прямых строк ответов. Они включены как зафиксированные первоначальные оценки 30 октября. Ещё 21 факт от 29 октября полностью повторяется уточнением от 30 октября; скрипт проверяет равенство и не учитывает их повторно. Исторические источники после 30 октября, переносы Q2 из workbook и команды типа «Продукт» в восстановление не включаются. Остальные текущие значения, включая зависимые оценки без выбранного исторического факта, остаются текущими.

Формула команды и уровни взяты из существующих `completeProductPercent` и `maturityLevelName`. Общая карточка DDI — округлённое среднее уже округлённых командных оценок, как в `DashboardPage`. Поля `meanOfRounded` показывают движение до финального округления; `meanOfRaw` — дополнительное среднее неокруглённых командных процентов, которое не используется карточкой.

Итог: среднее командных DDI 63,68421 → 63,80263 (+0,11842 п.п.), карточка 64 → 64. Меняются 11 значений у 9 команд; у 8 команд меняется отображаемый DDI. Единственный переход уровня: «Дети» 60 → 61, «Развивающиеся» → «Зрелые». У Top Affluent растёт неокруглённый DDI при сохранении отображаемого 61.

`scenario.json` содержит все 76 команд, сырые и округлённые DDI, уровни, каждую историческую пару с текущим и сценарным значением, provenance и SHA256 входных файлов. Встроенные проверки подтверждают неизменность источников, Q2, состава команд, весов, применимости, всех невыбранных метрик и последнего MAU ЕЛК 100%.
