# Проверка перезаписи бенчмарков, III квартал 2026

Проверены текущие эффективные оценки всех 76 команд. Оценки не менялись и не восстанавливались. Отдельный сценарий спутников для выбранных 11 команд сохранён без изменений; отменённый вариант инициатив ОСАГО не создавался.

**Необъяснённой потери последней действующей оценки не обнаружено.** Семь метрик у пяти команд, имевших прямые 100% 30 октября, сейчас ниже из-за более поздних явных пользовательских корректировок. Ещё одна метрика — отток «Конверсии» — стала нулём по условному правилу отсутствия отчётности. Эти восемь пар у шести команд нельзя автоматически считать дефектом и возвращать к 100%.

В активных overlays найдены **227 числовых исторических фактов**: 225 сопоставлены с 139 текущими парами `id/name/unit/type/code`; два вынесены отдельно за пределы текущего инвентаря метрик. Пятнадцать отличий сопоставленных исторических строк — это повторение семи пар из таблицы в источниках 29 и 30 октября плюс перенос Q2 «Конверсии». После учёта фактического приоритета расхождений с последним прямым фактом без переносов Q2 — **0**. Единственное расхождение с последним скалярным фактом вообще — «Конверсия»: условное правило отчётности применяется после скалярного переноса.

Два факта вне текущих пар относятся к одной метрике: **СберСпасибо, бенчмарки оттока = 0%** в источниках 29 и 30 октября. В текущем инвентаре такой метрики нет. Последняя явная CX-корректировка от 2 ноября (`cx-user-corrections-q3-2026.json`, строка пользовательского ввода 41) задаёт `applicable:false`, ответ «не релевантно». Это разрешённое исключение, а не потерянные 100%. Оба исходных факта и финальное основание перечислены в `outsideCurrentPairs`.

Из 77 прямых фактов от 30 октября полными были 20; семь из них позже снижены явными корректировками выше. Все 57 текущих источников `userConfirmedQuarterRetention` сохраняют полный балл. Два значения «Зарплатного продукта» проверены как равновесное среднее текущих B2B/B2C, а не как перезапись родительского ответа. Четыре PC-оценки, восемь сегментных нулей, отдельный ноль «СберЧаевых» и ноль привлечения ЦФА совпадают со своими прямыми источниками.

Правило отсутствия отчётности действует на пять benchmark-пар:

| Команда | Воронка | Без правила → сейчас |
| --- | --- | --- |
| Интернет-Эквайринг | Привлечение | Пропуск → 0 |
| Конверсия | Отток | 100% → 0 |
| Трансграничный эквайринг | Отток | Пропуск → 0 |
| ЦФА | Привлечение | Прямой 0 → 0 |
| Автокредит | Отток | Пропуск → 0 |

Для «Трансграничного эквайринга» настроенная отчётность впоследствии отдельно стала неприменимой (максимум 0). В provenance бенчмарка сохранено значение отчётности 0 на этапе применения правила; аудит различает это состояние и финальную неприменимость отчётности. Нулевой бенчмарк сам остаётся применимым. Это последовательность действующих правил, а не автоматическое восстановление исторической оценки.

Финальный workbook resolver, перезаписывавший знание спутников, работает только с блоком `general` и не затрагивает эти пять кодов. Для бенчмарков проверена фактическая последовательность: исходные overlays и full-Q2 retention → зарплатные когорты → условное отсутствие отчётности → PC-корректировки → УБ/CBP/CX-корректировки. Явные вложенные Q3-корректировки защищены от раннего retention и последующего УБ workbook.

Воспроизведение из корня:

```sh
node outputs/ddi-benchmarks-audit-2026-11-11/audit.mjs
```

Скрипт пишет только соседний `audit.json`. Экспорт `runAudit()` возвращает `{result,current}` без записи. Диагностические сборки без конкретного источника проверяют причину смены оценки; их результаты не применяются к данным. JSON содержит все 143 пары, 225 фактов с файлами и JSON pointers, текущие приоритеты, восьмёрку сниженных пар, пять условных нулей, подтверждение зарплатных средних и контрольные суммы. Имена респондентов и ненужные ответы анкет не экспортируются.

Встроенные assertions подтверждают воспроизводимость полного runtime, сохранность входных объектов, всего Q2 и SHA256 426 отслеживаемых production-файлов. Анализ не создаёт новый сценарий восстановления бенчмарков и не меняет старые экспорты.
