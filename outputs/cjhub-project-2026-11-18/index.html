01Ценность

Меньше ручной сборки.
Больше времени на анализ.

Описания клиентских путей хранятся в CJHUB. Команда может делиться ими и повторно использовать их в анализе.

Владельцу продукта и аналитику

  • Запросить воронку, среднее время по шагам, граф переходов или отчёт.
  • Переиспользовать найденные в CJHUB пути с учётом платформ и версий СБОЛ.

02Два рабочих сценария

Найти путь.
Или добавить свой.

Начните с того, что уже есть в общем хабе. Если нужного варианта нет, агент поможет разобрать ваше прохождение в СБОЛ.

Сформулируйте продуктовую задачу в GigaCode. Агент сам выбирает и сочетает необходимые навыки.

  1. АгентНайти подходящие пути

    Поиск по продукту в CJHUB с учётом платформ и версий СБОЛ.

  2. АгентСобрать составную спецификацию

    Альтернативные события одного шага объединяются через ИЛИ.

  3. АгентПередать события на расчёт

    Воронка рассчитывается по данным ClickStream. Дополнительно можно запросить тайминги, граф переходов или отчёт. Агент предупреждает о возможных пробелах покрытия.

  4. ПользовательПроверить покрытие и результат

    Пользователь экспертно проверяет спецификацию, покрытие и выводы.

Результат для разбора

Путь из общего хаба становится основой продуктовой аналитики.

  • Воронка по продукту
  • Среднее время по шагам
  • Граф переходов
  • Отчёт по запросу

Повторные прохождения объединяются по уникальному клиенту. Тайминг — среднее время на шаге.

Пройдите нужный сценарий в СБОЛ самостоятельно. Агент сопровождает разбор событий и помогает согласовать описание.

  1. ПользовательОставить узнаваемый след

    Введите в поиск СБОЛ специальную уникальную фразу и сообщите её агенту.

  2. АгентНайти своё прохождение

    Агент использует фразу, время и семантику событий, определяет хеши пользователя и устройства.

  3. АгентВыделить бизнес-шаги

    События и параметры связываются с шагами. Платформа и версия уточняются по данным пользователя и устройства.

  4. ПользовательПодтвердить путь

    Вы проверяете предложенные шаги и свободное бизнес-описание в диалоге.

  5. АгентСохранить в CJHUB

    После валидации агент записывает техническую JSON-спецификацию в общий хаб.

Один раз описать.
Использовать повторно.

CJHUB хранит последовательность событий и параметры. Согласованный путь доступен для совместного использования в следующих разборах.

Уникальная фраза помогает найти прохождение. Соответствие событий бизнес-шагам подтверждает пользователь.

Покрытие — отдельный вопрос. Даже найденный набор путей может не учитывать все варианты сценария. Предупреждение агента и проверка эксперта остаются частью работы.

06Начать работу

Подготовьте среду.
Задайте первый вопрос.

Коробка навыков распространяется через Атлас. Публикация содержит инструкции и ссылки на навыки в СберТреке.

  1. Забрать пакет из Атласа

    Откройте публикацию и скачайте навыки по размещённым ссылкам.

  2. Подключить оба MCP

    Настройте MJ MCP и OneWork MCP по инструкции. GigaCode будет интерфейсом общения с агентом.

  3. Начать с продуктовой задачи

    Сформулируйте запрос, затем проверьте найденные события, бизнес-шаги и результат.

Иллюстративный запрос для GigaCode
Найди в CJHUB пути оформления моего продукта в СБОЛ. Собери воронку и среднее время по шагам. Покажи найденные платформы и версии, возможные пробелы покрытия и то, что нужно проверить эксперту.

Перед первым запросом

Это отдельное приложение?

CJHUB — набор навыков и инструментов, которые агент выбирает и сочетает под запрос. Пользователь общается с ним в GigaCode.

Нужна ли экспертная проверка?

Да. Пользователь валидирует события, бизнес-шаги, спецификацию и выводы агента. Автоматическая сборка помогает подготовить анализ, а проверка остаётся частью процесса.

Найденная воронка покроет все варианты пути?

Набор путей в хабе может быть неполным. Агент предупреждает о возможном неполном покрытии и предлагает пополнить CJHUB новым проверенным путём.

Интеграция с CJXplorer уже работает?

Это дальнейший шаг в форме пилота. Планируется интеграция возможностей в CJXplorer командой CX Игоря Доронина. Опубликованных результатов пилота пока нет.
