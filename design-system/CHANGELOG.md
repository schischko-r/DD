# Изменения DDI Editorial

## 0.1.0 · 2026-11-18

Первая зафиксированная база для автономных документов и продуктовых страниц DDI. Статус компонентов — `documented`; это не выпуск корпоративной дизайн-системы и не полная сертификация доступности.

- Выделены токены из клиентского цикла, ОСАГО и CJHUB: палитра, типографика, сетка, плотность, размеры действий и SVG.
- Добавлены семантические текстовые цвета с проверяемым контрастом. Исходные `#139487` и `#7b8796` сохранены для подходящих индикаторов/неактивных состояний; существующие страницы не изменены.
- Зафиксированы контракты навигации, фильтра, подтверждаемого ссылкой чеклиста, числовых и sourced-полей, светофора, таблиц, схем, вкладок и навыков.
- Отдельно закреплён паттерн CJHUB: запрос → графический блок «Агент думает» (`{ }` → мини-воронка) → ответ-таблица, со стрелками между стадиями.
- Добавлены автономный каталог, общий CSS, сборка из JSON и проверки свежести производных файлов.
- Сборщик сохраняет одну завершающую новую строку в `ddi.css`, без пустой строки в конце файла.
- Документированы внесение изменений, роли, статусы, версии, миграции и исследованные первичные источники.

### Решения первой версии

| Решение | Основание | Следствие |
| --- | --- | --- |
| JSON — главный источник токенов | DTCG; необходимость повторять выбранный стиль без случайных значений | CSS и breakpoint собираются из JSON |
| Каталог остаётся обычным HTML | Текущие документы автономны и не требуют React | Нет установки Storybook или миграции Gravity UI |
| Состояние подкрепляется текстом и данными | Правки чеклистов, источников и светофоров | Цвет и галочка не могут подменять подтверждение |
| В блоке агента сохраняется графика | Пользователь отклонил варианты без картинок | Компактность достигается отступами, а не удалением графики |
| Измерения старых страниц не равны сертификации | Контраст исходного muted/teal ниже порога обычного текста | Новые семантические foreground; отдельная миграция старых страниц |

Миграция: для новых standalone-страниц использовать `ddi.css` и контракты каталога. Ранее выданные HTML не требуют немедленного изменения.
