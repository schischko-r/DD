# Сопоставление опросника с метриками «Вклады + НС»

Дата анализа: 8 октября 2026 года.

## Результат

**Для оценки остаются 10 основных вопросов и 5 вопросов с подтверждениями.** Они покрывают 11 метрик с неполным баллом. Ещё 3 метрики с неполным баллом не имеют прямого вопроса: гибкость условий продукта, инициативы сверх БП и CX Score.

**15 вопросов убираются из-за максимального балла соответствующей метрики; 1 вопрос — потому что метрики считаются по цифровым следам.** Три содержательных вопроса не связаны напрямую с оценкой метрик, а один вопрос о механиках имеет только частичное соответствие. Их нельзя автоматически считать лишними.

## Источники и правила

- Опросник: `Вопросы.xlsx`, лист **«Продукты (2)»**, содержательные строки 1–131. Ниже указаны номера строк Excel, а не порядковые номера вопросов. Строки с вариантами ответа не считаются самостоятельными вопросами.
- Баллы: `gravity-app/public/report-data.json`, продукт **«Вклады+НС»**, период **II кв. 2026**. В Excel нет столбцов «балл» и «макс. балл», поэтому правило равенства применено к соответствующей метрике в карточке продукта. Это не оценка ответов из Excel.
- Сначала исключены 8 метрик с цифровым подтверждением из предыдущего разбора. Отсутствие отметки цифрового подтверждения означает отсутствие такого подтверждения в карточке, а не доказанное отсутствие источника данных.
- Независимо от балла не опрашиваем по A/B-тестам и оценке исследований.
- Discovery исключаем только при наличии уже проанализированного бэклога на декомпозиции. В локальном `backlog-data.json` есть Top Affluent, ИнвестКопилка, Объект Авто и Рабочий возраст; вкладов нет. Поэтому наличие проанализированного бэклога вкладов не подтверждено, и строки 115 и 121 пока оставлены. Если такой бэклог есть в другой сборке, обе строки исключаются.
- Вопрос с несколькими метриками сохраняется только для тех вариантов, где балл ниже максимума. Вспомогательный запрос ссылки сохраняется, если подтверждает оставшуюся метрику.

## Не исключили ли мы лишнее?

**По заданным правилам признаков лишнего исключения нет.** Вопросы с максимальными баллами убраны именно по новому правилу; цели — по цифровым следам. При этом три метрики с неполным баллом остались в списке, но опросник их напрямую не проверяет. Это пробелы вопросов, а не результат исключения метрик.

Два ограничения сопоставления:

1. **Discovery нельзя исключать заранее для всех продуктов.** Для вкладов локально нет подтверждения проанализированного бэклога. В самом Excel комментарии к строкам 115 и 121 также предлагают считать долю самим, если дали пригодную ссылку.
2. **Не отождествлять исследование с рейтингом исследования.** Строка 122 просит описать факт исследования. Её отсутствие в оценочном блоке связано с отсутствием прямой метрики для этого вопроса; исключение рейтинга исследований не делает сам вопрос о последнем исследовании запрещённым.

## Предлагаемый состав опросника для вкладов

- Основные: **24, 38, 49, 61, 72, 80, 88, 96, 100, 115**.
- Подтверждения: **56, 79, 83, 91, 121**; ссылки на отчёты можно запросить один раз для каждой воронки.
- Добавить 3 точечных вопроса из таблицы выше — после проверки цифрового источника CX Score.
- Строку **105** использовать только как уточнение; **122, 123, 131** — как отдельные вопросы для контекста и планирования, без сопоставления с баллами.
- Если бэклог вкладов уже проанализирован, убрать **115 и 121**.

## Проверка полноты

Разобраны все **35 содержательных вопросов** на листе: 10 основных + 5 подтверждающих + 15 исключённых по максимальному баллу + 1 исключённый по цифровым следам + 1 частично соответствующий (105) + 3 контекстных (122, 123, 131). Вводные поля учтены отдельно. Для каждого исключения по максимуму проверено точное равенство `value == max_value`.
